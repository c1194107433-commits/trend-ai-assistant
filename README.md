# 潮玩种草 AI 助手

面向潮玩内容运营的网页工具。已完成视觉页面、预设样例、编辑、表达检查、复制及用户自带 Key 的 DeepSeek 接入。真实账户生成效果待用户验收，网站尚未公开部署。

## 在本机打开

需要 Node.js 20.9 及以上；本项目在 macOS、Node.js 26.11.1 下验证。

首次安装依赖：

```sh
npm ci
```

开发预览：

```sh
npm run dev
```

在浏览器打开终端显示的地址，默认是 http://127.0.0.1:3000。服务只监听本机，老师或其他设备不能通过这个地址访问。

正式构建和本地运行：

```sh
npm run build
npm run start
```

开发预览和正式运行二选一，同一端口不要同时启动。停止运行时在对应终端按 Ctrl+C。

## 体验流程

1. 点击右上角“查看演示样例”，选择云朵伙伴或慵懒瑜伽系列。
2. 点击“载入工作区”，预设资料与文案进入编辑区。已有内容时会先提醒替换。
3. 选择一个标题，修改正文与话题标签，表达检查会同步更新。
4. 点击“复制完整笔记”，复制的是当前选中标题、正文和标签，不包含界面提示。

需要真实生成时，点击“AI 设置”，填写自己的 DeepSeek API Key 并确认费用说明。保存设置不会调用 AI；填写商品资料后点击“生成笔记”，费用由该 Key 对应的账户承担。已有文案时先确认替换，失败保留原文案。

Key 和商品资料经本站后台转发至 DeepSeek 官方接口。Key 只在当前页面内存暂存，刷新或关闭后需重新填写，也可以主动清除。不要把真实 Key 发到聊天或写入项目文件。网站没有公共额度，也不会使用站长 Key 兜底。接入限制及验证见 [AI 接入记录](ai_integration.md)。

内容只存在当前页面中，不持久保存。需要保留的内容请及时复制。

## 表达检查

使用项目定义的 9 类短语规则，覆盖标题、正文和标签。命中表示需要人工复核，不代表违规判定；没有命中也不证明商品事实准确。

规则支持全角字符归一化、重叠短语去重和原文位置提示。引用、否定句可能命中，需要结合上下文判断。未选标题的提示与当前成稿分开显示。

规则文档：[风险表达检查规则](risk_review_rules.md)。

## 验证

```sh
npm test
npm run typecheck
npm run build
```

自动测试覆盖风险词重叠、全角文本位置、否定和引用、未选标题分离、示例文案，以及复制内容格式。浏览器验证记录见 [第一阶段验收记录](phase1_validation.md)。
